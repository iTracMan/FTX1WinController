# FTX1WinController
A Windows11 based controller for Yaesu FTX-1 via USB Cable. G1INU

## Download

Grab the latest release from the
[Releases page](https://github.com/iTracMan/FTX1WinController/releases/latest),
unzip it anywhere, and run `FTX1WinController.exe`. No installer, no .NET
runtime to install separately.

### About the SmartScreen warning

This app isn't code-signed — signing certificates cost money on an ongoing
basis, and this is a free hobby project, so that's a deliberate choice, not
an oversight. Because of that, Windows SmartScreen will likely show a blue
**"Windows protected your PC"** screen the first time you run the exe. This
is standard for any unsigned app and isn't a sign anything's wrong — to run
it anyway, click **"More info"**, then click **"Run anyway"**. You'll only
need to do this once per download.
